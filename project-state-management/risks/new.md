## NEW RISK IDENTIFICATION PROTOCOL

### When New Risk Identified:
1. **Document** risk with timestamp
2. **Assess** severity (Critical, High, Medium, Low)
3. **Analyze** impact on project
4. **Propose** mitigation strategy
5. **Add** to this file
6. **Move** to active.md when ready

### Risk Identification Triggers:
- New technology introduced
- New team member joins
- Scope changes
- External factor changes
- Lessons learned from mistakes
- User feedback

### Risk Assessment Criteria:
- **Likelihood**: How likely is this to occur?
- **Impact**: What is the impact if it occurs?
- **Severity**: Likelihood × Impact
